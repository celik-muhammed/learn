Primary Research Repositories
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* `arXiv
  <https://arxiv.org>`_
  (preprints in computer science, mathematics, physics, and statistics)

* `Papers with Code
  <https://paperswithcode.com/>`_
  (research papers linked to implementations and benchmarks)

* `Semantic Scholar
  <https://www.semanticscholar.org/>`_
  (AI-powered search engine for academic papers)

* `Google Scholar
  <https://scholar.google.com/>`_
