Core Learning Principles
----------------------------

.. note::
   For hands-on learning, follow this progression:
   
   1. **Interactive Exploration** — Use Streamlit Gallery or Observable notebooks to see live examples
   2. **Project-Based Courses** — DataTalksClub zoomcamps guide you through real-world problems step-by-step
   3. **Code from Examples** — Clone and modify working code from scikit-learn, TensorFlow, or PyTorch
   4. **Build & Share** — Create your own app with Streamlit or notebook with Jupyter, host on Hugging Face Spaces or Read the Docs

Learning Path: Step-by-Step
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

**Phase 1: Explore Interactive Examples**
  Browse Streamlit Gallery, Hugging Face Spaces, and Observable notebooks to understand what's possible.

**Phase 2: Choose a Learning Path**
  Pick a DataTalksClub Zoomcamp (Data Engineering, ML, or LLM) aligned with your goals.

**Phase 3: Work Through Projects**
  Complete the hands-on assignments, building real skills with practical datasets and tools.

**Phase 4: Study Production Code**
  Examine examples from scikit-learn, TensorFlow, or PyTorch to understand best practices and patterns.

**Phase 5: Build & Iterate**
  Create your own project, share it (Streamlit app, Jupyter notebook), and learn from community feedback.

**Phase 6: Deep Dive into Specialization**
  Once comfortable with fundamentals, explore advanced tutorials in your area of interest.
